# 14 分钟成人戏结构参考

用于 20 分钟成人短剧的默认配置。目标是让成人戏占主导，同时保持关系变化、可撤回同意和足够多的视觉信息。

## 总分布

```text
成人段 A：7分钟
非性反转：1分钟
成人段 B：7分钟
```

两段不能只是继续同一套动作。B 段至少改变以下五项中的三项：

1. 谁发起或掌握节奏
2. 衣物状态
3. 空间或体位
4. 速度、力度或接触方式
5. 关系条件、承诺或外部压力

## 成人段 A：接近与第一次完成

```text
0:00–1:00  距离、触碰、脱衣
1:00–2:30  手动或口交，确认边界
2:30–4:30  第一次插入与节奏变化
4:30–5:45  换主动方或换体位
5:45–6:30  第一次高潮
6:30–7:00  自愿停下、清理或未解决状态
```

段落 A 的重点是“允许发生”和“第一次失控”。第一次高潮后不要自动续上，应留下一个可见停顿。

## 中断反转

用 45–90 秒改变关系条件：

- 门外传来军情、脚步或时间限制。
- 一方说出真实身份、不能承诺的事项或必须做出的选择。
- 衣物复位，但身体反应没有结束。
- 求助方与掌握资源方必须把援助决定和性欲望明确分开。

## 成人段 B：选择与最终完成

```text
0:00–0:45  重新关门或重新确认
0:45–1:45  不同前戏、再次脱衣
1:45–3:45  新体位与主动方交换
3:45–5:45  更深的身体与关系升级
5:45–6:45  最终高潮
6:45–7:00  清理、喘息和关系后果
```

B 段的重点不是“再来一次”，而是一次带有新决定、新代价或新主动方交换的性行为。

## 节奏检查

每 60–90 秒至少发生一项：

- 衣物变化
- 行为阶段变化
- 主动方变化
- 体位或空间变化
- 同意或边界确认
- 外部压力出现

任何同一动作连续超过 90 秒，都需要在剧本上增加新的视觉或关系信息。

## 同意节点

以下节点至少写一次：

- 第一次触碰之前
- 衣物明显脱下之前
- 口交或其他新行为之前
- 第一次插入之前
- 改变体位或力度之前
- 任一方可能不适时

同意可以使用明确对白、点头和主动动作完成；不需要每次都写成法律问答。停止方式必须可见。

## 身体与镜头

每段至少覆盖以下画面类型：

1. 全身或中景：身体距离与权力位置
2. 面部近景：兴奋、迟疑、确认
3. 手部特写：触碰、脱衣、抓握
4. 性行为局部：接触方式、身体反应
5. 环境插入：门、衣物、床、隔离套、火光
6. 高潮与余韵：呼吸、停顿、清理

镜头不是为了把每个动作切成碎片，而是让观众始终知道谁在触碰谁、谁掌握节奏、身体处于什么状态。

## 对白

成人段中的对白只承担：

- 同意或停止
- 命令、请求、挑战
- 关系重新定位
- 时间或外部压力

不要把世界观说明、人物前史和完整作战计划塞进成人段。

## 交易防火墙

如果一方掌握救援、钱财、放行或军队：

- 性不能作为报酬。
- 援助决定必须在性之前或之后独立成立。
- 受压一方必须有不继续也不会失去帮助的明确余地。
- 伤者、俘虏或下属场景尤其要写清可拒绝与可离开。

## 结尾

最后 45–60 秒只完成：

- 清理或穿衣
- 一句确认关系变化的短对白
- 一个外部后果的画面

不要再用长解释总结主题，也不要在结尾突然展开新的世界观支线。
