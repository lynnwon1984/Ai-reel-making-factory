# 舞台单场写作

一次只写一个场景。先写初稿，再按问题定向扩写，不在一轮里自行宣布通过。

## 输入

```text
项目参数
精简故事圣经
前一场结束状态
当前场景卡
当前场对应事实或原文
下一场不得提前发生的内容
本场最低汉字预算
```

场景卡不完整时先列缺口。不得用旁白、闪回或新人物填坑。

## 输出格式

```text
S01 场景名

时间：...
地点：...
人物：...

【开场】
可见状态

【动作与调度】
可执行动作

周岚：台词

周启明：台词

【本场结束】
人物位置、关键道具、声音或灯光状态
```

台词行必须写真实人物短名，不能输出字面的“角色名：”。

## 写作规则

- 原文对白逐字保留；不得加字、减字或用同义句替换。
- 叙述信息优先转成现场证据、人物争执、可见物件或空间关系。
- 内心活动优先转成潜台词、停顿、躲避动作或物件操作；只有项目明确允许时才写独白。
- 舞台指示写现在时、可见动作。禁止镜头、景别、剪辑、蒙太奇、分屏和影视式旁白。
- 不写“气氛紧张”“命运降临”“时间仿佛停止”等无法执行的提示。
- 不解释人物已经知道的事。信息进入冲突、请求、威胁、隐瞒、交易或行动。
- 每一段新调度都要改变关系、信息、风险或节奏，不能靠复制同一动作凑长度。
- 不新增人物、地点、前史、证据、寄信人、遗言或下一场信息。

## 长度与节拍

- 2–3 分钟场次通常写 500–900 个汉字，至少 5 个可见调度节拍。
- 可把 2–3 分钟先按每分钟约 180 个汉字规划；对白稀疏的场面必须靠真实的权力变化和停顿支撑，而不是装饰性动作。
- 达到预算前不能总结收尾。若内容不足，把当前场的每条来源事实发展成一个新节拍，不得跳入下一场。
- 连续两次扩写仍达不到预算，输出 `STATUS: BLOCKED`，说明是场次拆分不足、材料不足还是模型长度能力不足；不要继续重复台词。

## 完成条件

场末必须达到场景卡 `CHANGE`，并给下一场留下所需的人物位置、秘密、承诺、道具和空间状态。
