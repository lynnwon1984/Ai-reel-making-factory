# 亲密场景工坊

把一场成人亲密戏写成连续发生、可视或可读的行为，而不是情绪形容词和器官名称的堆叠。

本 Skill 默认用于 AI 生成影视或小说场景。剧本模式中的动作谱用于生成、分镜和后期连续性，不是真人演员的现场安全说明。不要用“演员需亲密戏指导”替代具体的动作、衣物、身体位置和镜头覆盖。

## 使用边界

- 所有参与者必须明确成年、虚构并全程自愿。
- 不写未成年、真实人物、亲属间的性内容、非自愿性行为或具体性侵过程。
- 权力差、受伤、债务或救命情境中，弱势方必须有不继续也不会失去帮助的明确余地。
- 用户要求直白描写时，写清身体和动作；不强行用黑场、省略或隐喻替代。

## 输入

```text
输出模式: 小说 / 影视剧本
人物A:
人物B:
年龄或成熟阶段:
种族与身体差异:
关系与当前状态:
场景地点:
进入状态:
本次情欲目标:
冲突或边界:
允许的尺度:
禁止的尺度:
衣物:
道具与保护措施:
第一次高潮如何改变局面:
第二段如何升级:
结束时必须留下的状态:
```

信息不足但可以合理假定的事项先做暂定选择；年龄、同意、亲属关系和身体结构不明时不得猜成违规关系。

## 两种输出模式

### 小说模式

按视角人物的感知顺序写：

1. 先写距离、视线和即将发生的触碰。
2. 再写温度、压力、摩擦、重量、湿度、声音和气味。
3. 每次动作改变后，写身体位置和呼吸如何变化。
4. 用人物对当前触碰的反应表现欲望，不急着解释爱与不爱。
5. 高潮不是句子最多的地方，而是感知最集中、行动最明确的地方。
6. 结束后写清理、衣物、距离和一句或一个动作造成的不可逆变化。

不要连续使用同一类比喻。不要把每个动作都配一段心理分析。视角人物只能感知自己知道、看见、听见或触到的东西。

### 影视剧本模式

按动作节拍和镜头覆盖写：

```text
【亲密戏 S03-INT-01】
意图:
进入状态:

01. 距离或第一次触碰
02. 衣物与皮肤
03. 前戏方式
04. 主动方与节奏
05. 体位或空间变化
06. 第一次高潮
07. 停顿或清理

【镜头覆盖】
- 中景: 身体距离与权力
- 手部特写: 触碰与脱衣
- 局部特写: 行为与反应
- 面部近景: 确认、呼吸和失控
- 环境插入: 床、墙、衣物、保护措施
```

每次动作必须在画面上能判断：谁在触碰谁、碰到哪里、衣物状态、身体位置、谁掌握节奏。

## 通用结构

### 1. 进入

- 先确定两人当前距离和未解决的压力。
- 第一次触碰前写清谁靠近、谁没有退开。
- 可以用主动动作完成同意，但要让观众或读者能理解。

### 2. 前戏

手、口、视线、衣物和空间都参与前戏。前戏不是固定清单，而是让双方不断确认、试探和改变主动方。

### 3. 第一次性行为

写清接触方式、身体位置、节奏和保护措施。不要用“然后他们融为一体”跳过过程。

### 4. 第一次高潮

高潮必须改变节奏、主动权、关系或外部压力。一个人到达后，另一人是否继续必须明确。

### 5. 反转

两段亲密行为之间加入至少一项变化：

- 谁主动
- 衣物脱到哪一步
- 地点或体位
- 速度与力度
- 情感或政治条件
- 是否要继续

### 6. 第二次升级

第二次不是重复第一次。至少改变三项：主动方、空间、体位、前戏方式、接触节奏、保护措施或关系承诺。

### 7. 余韵

写呼吸、汗水、衣物、保护和清理。用一个动作或一句短对白说明关系已经不是进入时的状态。

## 身体连续性

每写到新的动作，都要知道：

```text
两个人站在哪里、坐在哪里或躺在哪里
衣服在上半身、腰间、膝弯还是已经落地
谁的手在哪里
谁在支撑身体
关键道具在谁手里或放在哪里
```

不能写完脱衣又突然出现完整衣物，也不能写手在背后同时抓住前方物件。

## 非人角色

非人角色先定义与场景有关的身体差异：

- 体温、皮肤、鳞片、翅膀、触须或毛发
- 可接受触碰的位置
- 特殊分泌物、气味或发光反应
- 生殖结构与保护措施
- 哪些反应是自愿表达，哪些只是生理反射

不要默认每个非人种族都拥有人类相同的身体和生殖方式。未定义时先提出具体设定，不用含糊比喻蒙混。

## 尺度控制

- **半显**：动作意图、衣物和关系变化清楚，生理细节更克制。
- **直白**：写清性器官、插入或口部动作、节奏、湿润、收缩、射精等可见反应。
- **更直白**：增加动作顺序、身体重量、体位转换和持续反应，但仍围绕双方目标与同意。

任何尺度都必须保留人物选择。越露骨，越不能把对方写成单纯被使用的物体。

## 语言检查

删除：

- 连续三个以上抽象情绪词
- 每句都出现的“滚烫、酥麻、破碎”
- 只写香气和烛光、不写动作的段落
- 不说明衣物和身体位置的跳跃
- 高潮后立刻恢复正常谈话的断层
- 用性别刻板印象替代人物声音

保留：

- 具体动词
- 身体重量和方向
- 呼吸和声音变化
- 主动方的选择
- 空间与衣物的连续性
- 结束后的现实后果

## 交付输出

小说请求：只输出场景正文；用户要求时再附身体/衣物连续性表。

剧本请求：输出场景头和亲密戏动作谱；用户要求时再附镜头覆盖表和英日版本。

修订请求：先列问题，再按指定范围修改，不擅自扩大到其他段落。
