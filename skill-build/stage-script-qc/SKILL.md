# 舞台剧本质检

先审计，后修复；审计和修复不要在同一轮自说自话。只报告可指出位置、可验证、可修改的问题。

## 输入

```text
项目参数
故事圣经
场景卡
当前场对应原文/事实
待审剧本
上一场结束状态（如有）
```

## 审计输出

```text
QC_SCOPE: S01 / 全稿
STATUS: PASS / REPAIR / BLOCKED

ISSUES
ID | SEVERITY | CODE | EVIDENCE | REQUIRED FIX
S01-Q01 | P0 | SOURCE_DRIFT | 短引文或精确位置 | 只改哪一处
```

没有问题时只输出 `STATUS: PASS` 和 `ISSUES: NONE`。不要输出分数。

## 问题代码

- `SOURCE_DRIFT`：新增、删除或改变关键事实。
- `QUOTE_MISMATCH`：受保护台词不是逐字原文。
- `MISSING_EVENT`：场景卡主事件没有发生。
- `EMPTY_SCENE`：场末没有变化。
- `BOUNDARY_BREACH`：提前写下一场事件。
- `UNMOTIVATED_ACTION`：行为缺少本场可见动机。
- `EXPOSITION`：人物说出双方已经知道的信息。
- `ON_THE_NOSE`：把潜台词或主题直接解释出来。
- `REPEATED_BEAT`：动作或台词重复凑长度。
- `STAGE_IMPOSSIBLE`：舞台、演员或转场无法执行。
- `FILM_GRAMMAR`：出现镜头、剪辑、景别或未经许可的影视旁白。
- `ENTER_EXIT`：进出场突兀或与开场状态冲突。
- `PROP_CONTINUITY`：道具来源、位置或去向错误。
- `DOUBLING_CONFLICT`：同场兼任或换装时间不足。
- `SCENE_TOO_SHORT`：低于该场时长对应的排练稿预算。
- `FORMAT_ERROR`：缺少必要字段或无法解析。

## 严重度

- `P0`：事实被改、受保护台词错误、舞台无法执行、提前越过场界。
- `P1`：人物动机、进出场、道具、连续性或核心场景目标明显受损。
- `P2`：局部节奏、用词、格式问题。

存在 P0/P1 时 `STATUS: REPAIR`。仅 P2 或无问题为 `PASS`。缺少必要输入为 `BLOCKED`。

## 检查方法

1. 将原文直接对白逐句比对，先查漏句和改字。
2. 将场景卡 `EVENT / TURN / CHANGE` 与剧本实际事件对照。
3. 检查场末是否真的发生了状态变化。
4. 检查下一场最早发生的事件有没有被提前写入。
5. 检查每次进出场、门界跨越和兼任换装。
6. 追踪关键道具的来源、所在位置和去向。
7. 扫描镜头语言、重复段落和模板占位。
8. 比较正文汉字数与场次时长预算。

## 定点返修

```text
REPAIR_MAP
S01-Q01 | FIXED / UNRESOLVED | 具体修改

REVISED_SCENE
完整场景
```

- 未列入问题的段落原则上保持原样。
- 受保护台词必须逐字恢复；只在原文中存在唯一近似候选时才做单字纠错，否则标 `UNRESOLVED`。
- 不新增事实、人物、证据或下一场内容。
- 不通过重复动作或台词凑长度。
- 修复后必须重新质检，不能在同一轮宣布通过。

整本围读稿额外检查：场次顺序、总时长中值、人物首次/末次出场、关键道具全剧轨迹、散文或影视术语残留。
