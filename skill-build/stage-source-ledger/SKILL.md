# 舞台素材事实账本

把原文拆成后续流程可直接引用的因果事实，不写场景，不做审美评价。默认处理中文；原文可以是小说、故事梗概、口述稿或剧本。

## 输入

```text
CHUNK_INDEX: 当前块序号
START_ID: S001
章节或段落范围: ...
原文: ...
```

一次最多处理 2500 个汉字。跨块时延续全局编号，禁止每块重新从 `S001` 开始。

## 输出格式

```text
CHAPTER_RANGE: ...

FACTS_JSONL
{"source_id":"S001","locator":"章节/段落","sequence":1,"when":"时间或[暂缺]","where":"地点或[暂缺]","who":["角色"],"event":"一个因果节拍","change":"具体改变了什么","quotes":[{"speaker":"角色","text":"逐字台词"}],"motifs":["原文意象"],"stage_trap":"媒介风险或 无"}

CONTINUITY_FLAGS
NONE

SOURCE_INDEX
S001 | 短标题 | 事件结果

COVERAGE
first_source_id: S001
last_source_id: S001
unparsed_text: 无
```

## 提取规则

- 按因果节拍切分，不逐句切碎。通常每 1000 字提取 3–8 条。
- 天气、气氛和背景若没有独立变化，并入最近事实的 `motifs`。
- 快速对话只推动同一个争执时合为一条，`quotes` 中保留全部原句。
- `change` 必须是知识、关系、权力、危险、承诺、决定或行动方向上的具体变化。不能为空，不能写“未解决”。
- `event` 用 10–80 字描述可观察动作与直接结果，不写主题、评价或“她终于明白”。
- 每个对象都必须包含全部 11 个字段，即使值为 `[暂缺]`、`[]` 或 `无`。
- 原文中由“说、问、答、喊、叫、道”引出的直接对白必须进入某个 `quotes`，不得漏句。
- `quotes.text` 逐字复制，不加“在、了”等字，不把转述冒充原句。
- 由上下文得出的判断标“推断：”；无法确定写 `[暂缺]`。
- `stage_trap` 写具体问题，例如“整场只有内心独白”“同一时刻发生在三地”；没有则写“无”。

## 自检

输出前逐项核对：

1. `source_id` 从 `START_ID` 连续递增。
2. 每条只有一个主事件，且 `change` 非空。
3. 原文直接对白没有漏句，已有引语能在原文中逐字找到。
4. `SOURCE_INDEX` 行数与 JSONL 行数相同。
5. 未处理的原文明确放入 `unparsed_text`。
6. 没有把推断写成事实。

发现漏句但无法确定归入哪条时，不要硬塞；在 `CONTINUITY_FLAGS` 中列明原文对白和候选 `source_id`，请求确认。
