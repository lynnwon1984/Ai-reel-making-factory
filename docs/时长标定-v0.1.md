# 故事时长 → 分镜时长标定 v0.1

日期：2026-11-05

## 目标

解决两个问题：

1. 为什么流程二估时 88 秒，分镜稿会变成 147–160 秒？
2. 一个 shot 应该给多少秒，而不是由模型凭感觉填写？

原则：

- 不让模型凭直觉决定最终秒数；
- 不把 15 秒当目标；
- 先计算内容预算，再用 5–15 秒容器做离散化；
- 模型给的时间只作为结果，不作为标准答案。

## 第一版时长模型

实现：

- `src/duration-calibration.js`

模型版本：

```text
duration-v1
```

参数：

```text
每个动作微单元：0.8 秒
中文台词：4.5 字/秒
英文台词：2.5 词/秒
每句台词基础停顿：0.4 秒
最短 shot：5 秒
最长 shot：15 秒
容差：0.75 秒
```

计算公式：

```text
内容预算 =
动作微单元数 × 0.8
+ 台词字数 / 语速
+ 台词停顿

建议 shot 时长 =
clamp(ceil(内容预算), 5, 15)
```

这里不用“向 15 秒填充”。

## 为什么旧估时只有 88 秒

旧算法按“一个动作源块 0.8 秒”计算。

但一个动作源块内部可能包含多个动作微单元：

```text
B16 盾破、击倒、吐血、痛苦喊叫
```

旧算法：0.8 秒  
动作微单元：4 × 0.8 = 3.2 秒

62 源块整场重算后：

```text
旧估时：约 88 秒
动作微单元预算：约 138.4 秒
```

这说明旧版不是“模型故意把时长拉长”，而是本地低估了动作量。

## 与真实分镜对照

使用官方动作规则生成的 62 源块分镜：

```text
runs/director-pilot/2026-11-05T08-50-24-947Z/
```

结果：

| 指标 | 数值 |
| --- | ---: |
| 动作与台词内容预算 | 138.4 秒 |
| 按最短 shot 离散后的建议总时长 | 161 秒 |
| 模型实际分镜总时长 | 160 秒 |
| 实际 / 内容预算 | 1.16× |
| 实际 / 建议时长 | 0.99× |
| 单镜平均绝对误差 | 1.09 秒 |
| 平均偏差 | -0.04 秒 |
| 内容预算不足的 shot | 4 |

这说明：

> 动作微单元预算已经能解释绝大部分分镜时长。

不足的 4 个 shot：

- shot01：内容 7.2 秒，实际 6 秒；
- shot03：内容 11.2 秒，实际 6 秒；
- shot04：内容 10.8 秒，实际 7 秒；
- shot08：内容 6.8 秒，实际 6 秒。

其中 shot03 和 shot04 正好也是动作阶段拆分尚未完全解决的区域。

## 独立 Schema v3 分块验证

输入：

```text
11 源块
约 20 秒规划段
```

结果：

| 指标 | 数值 |
| --- | ---: |
| 内容预算 | 19.6 秒 |
| 建议总时长 | 27 秒 |
| 实际总时长 | 25 秒 |
| 内容不足 shot | 1 |

不足的是最后一条 shot：

```text
内容预算：6 秒
实际时长：5 秒
缺口：1 秒
```

这与校验器此前发现的“2.8 秒内容放进 2 秒 Clip”一致。

## 当前可靠结论

1. `0.8 秒 / 源块`不可靠，会严重低估动作。
2. `0.8 秒 / 动作微单元`目前比源块计数稳定得多。
3. 在现有真实样本上，动作微单元 + 台词预算可以解释 160 秒总时长中的绝大部分。
4. 剩余误差主要来自：
   - 最短 shot 5 秒造成的取整；
   - 一个 shot 内多个动作阶段；
   - 对白反应和镜头切换余量；
   - 动作类型的差异。
5. 当前只是单个 62 源块样本的标定，不是跨题材通用常数。

## 本地校验

Schema v3 下新增两项检查：

- 每个 Clip 的内容预算不得明显超过 Clip 时长；
- 整个 shot 的内容预算不得明显超过 shot 时长。

低于预算时只报告缺口，不自动宣判“应该拉到 15 秒”。

## 下一步

### P0

把同一套预算跑在至少 3–5 个不同类型的场景上：

- 对话场；
- 动作场；
- 多人调度场；
- 空镜/氛围场；
- 特效场。

### P1

拆分动作类型，而不是所有动作微单元都用 0.8 秒：

- 眼神/表情；
- 手部动作；
- 身体位移；
- 接触和交接；
- 倒地/撞击；
- 群体动作；
- 特效爆发。

### P2

用真实配音和成片时长做校准，不再只对照模型生成的分镜时长。
