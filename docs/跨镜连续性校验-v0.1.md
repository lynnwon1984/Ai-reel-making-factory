# 跨镜连续性校验 v0.1

日期：2026-11-05

## 目标

检查上一镜 `endState` 能否合理接住下一镜 `startState`，重点抓：

- 无来源姿势跳变；
- `continuityNote` 只写“同上”“沿用上一镜”；
- 上镜终点和下镜起点完全没有承接；
- 人物进出画状态，仅记录，不直接报错。

## 实现

入口：

```text
auditShotContinuity(plan, sceneInput)
```

每个相邻 shot 对比较：

- 上一镜 `endState`
- 本镜 `startState`
- `continuityNote`
- 本镜可见动作
- 人物集合变化
- 姿势状态

## 高分问题

以下情况直接报高：

1. `continuityNote` 为空，或只写“无 / 无变化 / 保持不变 / 同上 / 沿用上一镜状态”；
2. 上一镜终点是站、坐、跪、蹲、躺、倒地之一，本镜起点变成另一种姿势，但承接说明没有写出新姿势及其来源动作。

例：

```text
上一镜终点：林岚站在门口。
下一镜起点：林岚坐在桌后。
承接说明：沿用上一镜状态。
```

这是明确冲突，报高。

合法写法：

```text
上一镜终点：林岚站在门口。
下一镜起点：林岚坐在桌后。
承接说明：林岚走进屋内，在桌后坐下。
```

## 中分问题

如果：

- `continuityNote` 没有声明时间、地点、转场或承接；
- 上一镜终点与本镜起点文本相似度低于 12%；
- 两边没有共同在场人物；

则报“没有可见承接桥”。

## 人物进出画

人物从 `cast` 中出现在下一镜或从下一镜消失，**不直接报错**。

原因：

- 切换景别时人物可以出画，不一定真正离场；
- 近景、特写、反打都可能只保留部分人物；
- 仅凭 shot 人物表无法证明人物进入或离开场景。

目前只记录：

```text
entering
leaving
```

供后续语义审查使用。

## 已修掉的误报

第一版把人物不在下一镜 `cast` 中直接当成“离场”，结果在真实稿件里产生大量误报：

- 村民切到近景时出画，被误判为离场；
- 黑龙在空中切换到人物近景时出画，被误判为离场；
- 导师组切到亚瑟单人镜头时出画，被误判为离场。

因此改为：

> 人物出画只记录，不推断离场。

## 测试覆盖

- 同一人物、姿势、持物和视线可直接承接；
- 站变坐但没有来源：高风险；
- “沿用上一镜状态”：高风险；
- 人物出画但仍在场景：不报错；
- 真实 23 shot / 5 shot：零误报。

## 局限

仍未自动解决：

- 左右手换手是否合法；
- 道具是否在不该消失时消失；
- 视线方向和 180 度轴线；
- 门、桌、王座等空间锚点是否跳变；
- 人物确实进场/离场但没有写进说明。

这些需要下一步增加“持物状态 + 场景锚点 + 视线方向”的结构化账本。
