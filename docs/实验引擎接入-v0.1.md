# 流程三实验引擎接入 v0.1

日期：2026-11-06

## 页面入口

流程三新增“引擎”选择：

```text
稳定链路（默认）
实验引擎
```

旧链路完全保留。实验引擎只作为显式开关，不自动替换默认生成。

## 实验链路

```text
分集剧本
→ 按集和场解析
→ 生成导演提示单
→ 生成动作微单元 Schema v3 镜头计划
→ 本地结构 / 动作 / 时长 / 去重 / 连续性校验
→ 高风险定点修复
→ 编译标准分镜 Markdown
→ 进入现有预览、校验和分镜交付包
```

## 页面配置

实验模式下可调整：

- 推理档位：`low` / `minimal`
- 分块预算：15–30 秒，默认 20 秒
- 导演提示单：内置可读、可替换
- 镜头计划 v3 提示词：内置可读、可替换

提示词留空时使用默认内容。

## 进度保存

实验模式复用 `pd-storyboard-v1`，并额外保存：

- 当前批次；
- 已完成集结果；
- 已完成场结果。

刷新或切换页面后，已完成的集和场会跳过，从未完成的场继续。

## 质量门

实验引擎返回的结构问题会显示在步骤 04：

- 动作阶段过载；
- Clip / shot 内容预算不足；
- 重复镜头职责；
- 跨镜连续性冲突；
- 源内容未覆盖或重复引用。

只要存在高优先级问题，就阻止下载交付包，但不删除已有产出。

## 当前边界

- 实验模式尚未替换旧链路；
- 修复仍是整分块修复，不是“只修失败 shot”；
- 没有完成跨题材三场正式 A/B；
- 页面还没有展示短集重分配决策卡；
- `minimal` 和第二轮定点修复仍属于实验参数。
