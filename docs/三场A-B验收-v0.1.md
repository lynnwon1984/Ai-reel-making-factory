# 稳定链路 vs 实验引擎：三场 A/B 验收 v0.1

日期：2026-11-06

## 结论先行

实验引擎已经在真实页面和真实模型上跑通，但**不能设为默认**。

它的优势：

- 每镜有职责、动作阶段、时长预算和连续性审计；
- 问题能被明确挡住，不会静默交付。

它的问题：

- 动作场仍留下 4 个高风险结构问题；
- 多人场留下 2 个高风险结构问题；
- 分镜数量和总时长普遍上涨；
- 三场的台词语义覆盖与稳定链路一样，都是 100%；
- token 成本约为稳定链路的 6.0 倍；
- 修复调用占总 token 的 43%–54%，仍然过高。

当前建议：

```text
稳定链路继续作为默认
实验引擎保持显式开关
先用失败 shot 定点修复压低成本和质量缺口
```

## 分场判断

### 对白场 5-1

稳定链路：

- 镜头更紧凑；
- 14 句源台词语义全部覆盖；
- 模型会把一句原文拆成多条 `EN` 行，早期“精确行覆盖”统计误把拆分算成漏句，现已改为包含性语义覆盖。

实验引擎：

- 14/14 句台词全部覆盖；
- 递粥、钱袋、情绪变化和阻挡关系拆得更明确；
- 结构和 QC 高问题为 0；
- token 约为稳定的 5.2 倍。

判断：

> 两种链路台词都完整；实验引擎多出的是导演结构和连续性字段，但 token 约高 5.2 倍。

### 动作场 4-2

稳定链路：

- 12 shot，节奏更紧凑；
- 台词覆盖 100%；
- 出现一条“亚瑟：（无台词）”伪台词，被引擎判为台词篡改。

实验引擎：

- 21 shot，动作阶段拆得更细；
- 台词覆盖 100%；
- 仍留下 4 个高风险问题：
  - Clip 内容预算 9.2s 超过 8s；
  - Clip 内容预算 9.2s 超过 5s；
  - 一个 Clip 缺少源引用；
  - “坐→站”姿势变化缺少来源说明。

判断：

> 实验引擎更细，但动作场还没有达到可默认交付的稳定性。

### 多人调度场 8-1

稳定链路：

- 3 shot / 6 Clip；
- 3 句源台词全部覆盖；
- 台词拆成多条 `EN` 行时会被旧的精确行统计低估。

实验引擎：

- 5 shot / 8 Clip；
- 3/3 句台词全部覆盖；
- 仍留下 2 个高风险问题：
  - 一个 Clip 内容预算 10.4s 超过 8s；
  - 一个 Clip 缺少源引用。

判断：

> 两种链路台词都完整；实验引擎增加了镜头拆分和结构审计，但仍有源引用和内容预算问题。

## 成本发现

实验引擎修复调用占比：

| 场景 | 修复 token 占比 | 修复耗时占比 |
| --- | ---: | ---: |
| 对白场 | 48.7% | 43.2% |
| 动作场 | 49.2% | 43.7% |
| 多人场 | 53.9% | 54.1% |

说明：

> 当前“整块修复”是实验链路最大的成本漏洞。下一步必须改成只返回失败 shot，而不是重发整块。

## 已验证的产品能力

- 稳定链路和实验引擎可以在同一页面切换；
- 实验模式支持自定义导演提示单和镜头计划 v3；
- 实验模式刷新和切页后不丢输入、模式、已完成集和已完成场；
- 实验高问题会阻止交付；
- 实验输出可以走完整分镜、分集分镜和 ZIP 交付；
- 9:16 竖屏提示词已生效。

## 下一轮优先级

### P0 实现状态（2026-11-06）

已完成代码、确定性测试和 8-1 真实复测；4-2 的第一次中间复测早于“第二轮修复 + 长台词延续”，不能作为最终指标。

1. `src/shot-repair.js` 已实现 `shot_replacements_v1`：只返回问题 shot 和替换范围，邻镜仅作只读上下文；合并前校验范围、重叠和空替换。
2. 生成链路已改为“先本地确定性修复，再判断是否调用模型”。人物短名、短 Clip、宽景别对白、可精确命中的源引用和动作内容超载不再直接触发模型修复。
3. 动作 Clip 过载会按动作微单元边界拆 Clip；若拆分后 shot 超 15 秒，继续在 Clip 边界拆 shot，不删动作、不填满时长。
4. 可见动作原文可精确命中源块时，确定性回填 `sourceBlockIds/actionUnitIds`；无法安全判断的仍交给局部模型修复。
5. `normalizeStoryboard()` 已删除“无台词/沉默”伪 `EN` 行。
6. 长台词跨多个 Clip 时，首段用 `sourceBlockIds`，后续段用 `dialogueContinuationIds`。这样既保留真实口型延续，也只编译一条 `EN`。
7. 定点修复最多两轮，第二轮只处理第一轮后仍未清掉的 shot。
