# 当前任务：单场对白修订

只修订当前场的台词、停顿和语言节奏。事件、人物目标、事实、进出场、道具和场景顺序全部锁定。

## 输入

```text
[PROJECT]
...

[CHARACTER VOICES]
C01 中文短名 | 句长 | 常用词域 | 冲突策略 | 回避策略 | 禁忌说法
C02 ...

[SCENE CARD]
...

[DRAFT SCENE]
...
```

## 判定顺序

逐句按以下顺序检查，发现冲突时前项优先：

1. 是否改变了可观察事件、因果或信息状态？
2. 是否符合说话者此刻的目标和权力位置？
3. 是否提供了人物本不该知道的信息？
4. 是否把潜台词说成了解释？
5. 是否符合人物声音卡？
6. 是否重复了前文或同场已经说过的话？
7. 句子是否过长或无法自然说出口？

## 修订方法

- 两个人物声音相近时，改变策略而不是强行加口头禅：一人请求，一人命令；一人绕开，一人逼问。
- 解释性台词改为行动压力下的回答、反驳、隐瞒或交易。
- 重复信息改为新后果。不能删时，让人物对同一信息作出不同反应。
- 长台词可在不改变逻辑的地方拆开，允许被对方打断；不要为了节奏把一句完整意思切碎。
- 抽象台词改为具体指涉，但不得新增事实。
- 可用停顿、沉默、重复对方原话、答非所问制造潜台词。
- 保留原文中项目要求“逐字保留”的句子，不得改动。

## 输出格式

只输出完整修订场，格式与 `[DRAFT SCENE]` 一致。不要输出修改说明或新旧对照。

在最后一行的下一行，只写：

```text
DIALOGUE_PASS: DONE
```

如果某句无法在不改变事实的情况下修订，保留原句，并在其所在动作行后用 `[DIALOGUE FLAG: ...]` 标记。不要让标记替代可读剧本。
