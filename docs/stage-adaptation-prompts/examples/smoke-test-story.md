# 烟雾测试故事：借伞

这段文字只用于测试提示词链路，不用于正式改编。

---

六月的雨落在修表铺的玻璃上。周岚已经二十年没回这座城。她站在门外，看着柜台后那个熟悉的背影，心里想：如果他回头，我该叫哥，还是叫周师傅？

周启明没有回头。他把一只坏掉的怀表放进抽屉，说：“修表要排队。急也没用。”

周岚从包里拿出一个装伞的旧布袋。袋口绣着“岚”字。周启明的手停了一下，仍然没有接。

“妈把铺子留给我了。”周岚说。

“她走的时候，你不在。”

“我在医院。”

“我在家。”

门外一个送信的年轻人敲了敲玻璃，留下一个没有署名的信封。信封里只有一把钥匙和一张写着地址的纸。周岚认出那是母亲旧屋的地址。

周启明把怀表从抽屉里拿出来，表盖内侧嵌着周岚小时候的一张小照。他问她：“现在去，还是明天去？”

周岚看着钥匙，说：“现在。”

周启明关掉柜台灯。两人没有拿伞。雨声盖住了关门声。

## 这段样本故意设置的改编陷阱

1. 全段有大量第三人称内省，不能把“她心里想”直接变成镜头或未经项目批准的画外音；优先用有限对白和对手戏呈现。
2. “二十年没回城”“母亲去世”“兄妹失和”必须由行动和有限对白逐步揭示，不能开头一次性介绍。
3. 修表铺、旧屋和雨是三个空间/声音系统，必须规定如何转场。
4. 伞袋、怀表、钥匙是有来源的关键道具，必须追踪去向。
5. 周启明何时决定接纳妹妹，必须有可见转折，不能只靠最后一句“现在去”突然和解。
6. 信是谁送的、钥匙为何在这时出现，原文没有说明，不能自行补出寄信人。
