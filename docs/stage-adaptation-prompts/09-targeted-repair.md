# 当前任务：定点返修单场

只修质检表列出的问题。没有问题的段落、动作和台词必须逐字保留。不要顺手润色，不要补写新的冲突。

## 输入

```text
[SCENE CARD]
...

[FINAL SCENE]
...

[ISSUES]
...

[PROTECTED LINES]
项目要求逐字保留或已经人工确认的句子
```

## 输出格式

先输出修补映射，再输出完整场景：

```text
REPAIR_MAP
S##-Q01 | FIXED / UNRESOLVED | <具体动了哪一处，为什么这样修满足要求>
S##-Q02 | ...

REVISED_SCENE
<完整场景正文>
```

## 返修规则

1. 每条问题都要在 `REPAIR_MAP` 中有对应行。
2. `FIXED` 表示问题已解决，不是“尝试过了”。
3. 需要新增事实才能修复时，写 `UNRESOLVED`，说明缺少的事实，不得自行补编。
4. 未列出的内容原则上保持逐字不变；因语法或衔接造成的最小改动可以发生，但必须写在对应 `REPAIR_MAP`。
5. 如果两条返修互相冲突，优先修复更严重的 `P0`，另一条标 `UNRESOLVED`。
6. 不调整场次顺序，不改变角色目标，不添加新人物、新证据或新结局。
7. 修补后要自然达到原 `[SCENE CARD]` 的 `CHANGE` 和下一场 `ENTRY_STATE`。

返修完成后，必须用 [08-qc-audit.md](./08-qc-audit.md) 重跑质检。不要在同一轮里自检并宣布通过。
