# 当前任务：写单场舞台剧本初稿

根据当前场景卡和对应原文，写 **一场且只能是一场** 舞台剧正文。不要写下一场，不要写全剧总结，不要解释改编意图。

## 输入

```text
[PROJECT]
...

[STORY BIBLE]
仅保留制作命题、主角、人物声音卡、舞台世界、兼任表、母题

[PREVIOUS]
PREVIOUS_EVENTS: <前两场已经发生什么>
ENTRY_STATE: <人物关系、情绪、身体、道具、空间状态>

[CURRENT SCENE CARD]
...

[SOURCE]
只放本场对应 S### 原文

[NEXT BOUNDARY]
本场必须留下的状态：<人物位置、秘密、承诺、道具、危险>
不得提前发生：<下一场事件>

[DRAFT BUDGET]
最低汉字数：<按场景时长计算；2–3 分钟场次至少 600>
```

## 输出格式

```text
S<场次>　<场名>

时间：<舞台可见/可听出的时间>
地点：<具体空间>
人物：<按舞台首次可见顺序；标明兼任关系仅在需要时>

【开场】
<人物已经在做什么。写可见状态，不解释背景。>

【动作与调度】
<只写观众能看见、演员能执行的动作。必要时逐条写。>

周岚：<台词>

（周岚把布袋放到柜台上）

周启明：<台词>

【本场结束】
<角色位置、关键道具、灯光或声音的结束状态；无必要则省略。>
```

## 写作规则

1. **一景一调用**：如果本场预计超过 2400 个中文字符，写到当前场景卡的主转折完成处停下，并在末行写 `CONTINUED: S##A`。不要自行增加第二转折。
2. **事实优先**：原场必须发生的事件、变化和结果为不可动项。舞台动作只能把已有事件实现出来。
3. **媒介翻译**：
   - 叙述者信息优先变成现场证据、人物争论、可见物件或空间关系。
   - 内心独白优先变成潜台词、停顿、逃避动作或对物件的行为；仅当人物声音卡允许时才写成独白。
   - 时间跳跃优先用灯光、声音、服装、道具变化或固定转场语法实现。
   - 无法在不新增事实的情况下表达的信息，写 `[STAGE PROBLEM: ...]`，不得自行补情节。
4. **对白**：用角色当下目标驱动。允许简短回答、打断、沉默和答非所问。不要把主题写成口号，也不要让角色讲解观众刚看过的事。
5. **舞台指示**：只写现在发生的事。禁止镜头词。抽象情绪优先改成动作，但不得机械地让每个情绪都配一个道具。
6. **语言经济**：删除可被表演替代的解释。每句台词都应改变、试探、隐藏或推迟某件事。
7. **边界控制**：本场结束时必须达到 `[NEXT BOUNDARY]` 的状态，不得提前释放下一场的信息。
8. **实际内容量**：按场景卡 `EST_MINUTES` 写作，并达到 `[DRAFT BUDGET]` 的最低汉字数。2–3 分钟的场次通常需要 500–900 个汉字和至少 5 个可见调度节拍，不能用氛围描写或空动作灌水。
9. **长度不足时继续写**：如果尚未达到预算，不得总结收尾；继续推进本场既有的 `OBJECTIVE`、`OBSTACLE` 和 `TACTICS`，用新的停顿、尝试、物件操作和有限对白加深冲突。不得为了长度新增事实、换场或提前完成下一场事件。

## 不许做的事

- 不许补写新人物、新证据、新前史或新结局。
- 不许把场景卡里没有的主要转折塞进本场。
- 不许让角色用台词互相介绍双方已经知道的信息。
- 不许在台词行写“角色名：”“说话人：”等模板文字；必须替换成具体人物短名。
- 不许用“气氛凝固”“命运降临”“时间仿佛停止”等无法执行的指示。
- 不许输出创作说明、修改记录或“下一场建议”。
