# 当前任务：只扩写当前场，不改剧情

当前场的事实、对白、人物目标、转折和结尾状态已经锁定。你只能增加本场已有的动作尝试、停顿、空间移动和有限反应，使正文达到 `[DRAFT BUDGET]`。

## 输入

```text
[SCENE CARD]
...

[CURRENT SCENE]
...

[SOURCE FACTS]
当前场的 S### 事实账本

[PROTECTED LINES]
必须逐字保留的原文对白

[FORBIDDEN]
下一场才能发生的事件和台词

[DRAFT BUDGET]
最低汉字数
```

## 扩写规则

1. 现有每一句台词和每一个事实动作都保留，不得删除、改写或重复。
2. `[SOURCE FACTS]` 中每条事实都要至少发展成一个可见舞台节拍；不得跳过事实，也不得把多条事实压成一句概述。
3. 只增加本场 `OBJECTIVE → OBSTACLE → TACTICS` 的尝试与反尝试。
4. 可以用停顿、关门/开门、跨过或不跨过门槛、拿起或放下物件、改变站位、避让视线来延长博弈，但必须改变人物关系或行动压力。
5. 每条 `[PROTECTED LINES]` 必须逐字出现一次；不得增字、减字或改用同义句。
6. 不新增人物、地点、前史、证据、寄信人、母亲遗言或下一场信息。
7. 不提前写出 `[FORBIDDEN]` 中的事件、台词或同义解释。
8. 不重复已经写过的动作和台词；每次扩写都要产生新的舞台状态。
9. 达到预算后立即停在本场 `CHANGE` 完成处，不写总结、下一场或修改说明。

## 输出

只输出完整修订后的当前场剧本。不要输出 `REPAIR_MAP`、新旧对照、扩写理由或结尾说明。
