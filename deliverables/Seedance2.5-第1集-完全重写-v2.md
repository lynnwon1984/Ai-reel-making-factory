## 使用说明

- 画幅：在生成页面或 API 设置为 `9:16`，不写入 Prompt。
- 时长：在生成页面或 API 设置为 `4–30` 秒或自动，不写入 Prompt。
- 本文件把第1集拆成 15 个连续生成单元。每段只承担一个主事件，阶段只控制因果顺序和结束状态。
- 每段只上传该段列出的素材，并按该段列出的顺序编号。因此该段的 `@Image1` 与另一段的 `@Image1` 可以是不同资产。

- 本文件不对无来源信息作补充。Brian、Lothar 的服装与飞剑归属仍以正式资产和剧本为准。
