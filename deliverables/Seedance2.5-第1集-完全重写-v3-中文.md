## 使用说明

- 画幅在生成页面或 API 中设置：`9:16`，不写入 Prompt 正文。
- 时长在生成页面或 API 中设置：`4–30` 秒或自动，不写入 Prompt 正文。
- 本文件按照第1集剧情顺序拆成 15 个连续生成单元。
- 每个生成单元只承担一个主事件，阶段负责说明因果顺序、可观察动作和结束状态。
- 每个生成单元只上传该段列出的素材，并按该段列出的顺序编号。因此不同生成单元中的 `@Image1` 可以是不同资产。
- 不要一次把所有素材上传到同一个请求。如果制作流程必须一次上传全部资产，需要在对应 Prompt 中逐个补列 `【未使用资产】`。
- 除原有英文台词外，Prompt 正文全部使用中文。
